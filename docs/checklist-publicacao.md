# Checklist de Publicação

## Revisão de conteúdo

- Validar textos institucionais
- Validar CTAs
- Validar nomes dos módulos
- Revisar ortografia e consistência de tom

## Imagens

- Substituir placeholders de logo
- Substituir hero por ativo definitivo
- Substituir por capturas reais do sistema, se entrarem nesta fase
- Confirmar favicon final

## Contatos

- Confirmar e-mail público
- Revisar links `mailto:`

## Responsividade

- Testar celular
- Testar tablet
- Testar notebook
- Testar monitor grande

## Acessibilidade

- Navegação por teclado
- Foco visível
- Contraste
- Textos alternativos
- `prefers-reduced-motion`

## SEO

- Revisar título e descrição
- Revisar Open Graph
- Revisar dados estruturados
- Validar sitemap e robots

## Domínio

- Confirmar canonical final
- Confirmar redirecionamentos esperados
- Não alterar DNS sem aprovação

## Analytics

- Confirmar ferramenta a ser usada
- Inserir scripts apenas após aprovação
- Validar consentimento apenas se houver coleta nesta fase

## Build

- Executar `npm install`
- Executar `npm run build`
- Executar `npm run preview`

## Revisão dos sócios

- Aprovação comercial
- Aprovação visual
- Aprovação para publicação
